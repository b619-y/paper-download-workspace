# 团队体系

本工作区把「检索 → 初筛 → 下载 → 解析 → 全文证据 → 数据提取」组织成一支分工明确的团队。
本文只说明**谁负责什么、怎么交接、边界在哪**；每个角色的具体指令见 [`.codex/agents/`](../.codex/agents/)，权威状态和合同见 [系统架构](系统架构.md)、[`00_control/POLICIES.md`](../00_control/POLICIES.md) 与 [`01_shared/contracts/`](../01_shared/contracts/)。

## 分工

| 小组 | 角色 | 只负责 | 明确不做 |
|---|---|---|---|
| 总控 | `workflow_coordinator_agent` | 先读真实状态，定位阶段，只推进下一个最小安全动作；调度其他角色 | 不跳步，不重做已完成阶段，不下研究判断 |
| 总控 | `langgraph_coordinator_agent`（可选） | 编排检索式、多源检索、题名摘要初筛，直到产出一个已校验的 READY 下载批次，然后停止并交回 | 不是第二套状态机；READY 之后不再推进 |
| 总控 | `recovery_agent` | 异常时只读诊断，执行白名单内可逆的安全修复 | 不改权威队列，不释放 lease，不改 hash、授权或人工验收 |
| 检索 | `query_agent` | 研究问题 → recall / balanced / precision_pilot 三套多库检索式，并用种子论文验证 | 不执行检索 |
| 检索 | `search_agent` | 调用九个学术 API，完整分页导出，保存原始响应与 `run_manifest.json` | 不去重，不筛选 |
| 检索 | `dedup_agent` | DOI 优先、规范化题名加年份次之去重，保留来源与冲突审计 | 身份冲突不自行裁决，交人工 |
| 初筛 | `abstract_screening_agent` | 用 ASReview 对题名摘要排序，辅助初筛 | 分数只用于排序，不当作纳入结论 |
| 初筛 | `criteria_screening_agent` | 按显式标准给题名摘要逐条候选判断 | 未获本次任务授权，不向外部模型发送题名摘要 |
| 获取与解析 | `download_agent` | 领取批次，经授权渠道下载全文，记录来源、哈希与大小 | 不绕过访问控制，只写已领取批次 |
| 获取与解析 | `document_processing_agent` | 已验收全文 → PDF→MinerU 或 XML→Markdown，回填索引 | 原文默认不上传外部服务 |
| 证据与提取 | `fulltext_screening_agent` | 基于全文、表格和图做证据复筛 | 只处理身份已核验且可读的全文 |
| 证据与提取 | `paperqa_luna_agent` | PaperQA 式独立检索候选，由 Luna 输出可复核的结构化候选证据 | 候选不等于结论，须回原文复核 |
| 证据与提取 | `data_extraction_agent` | 按任务数据合同从已解析全文批量生成带证据的结构化候选，人工复核后交付 | 不改原件；输入只接受经校验的不可变副本 |

仓库外还可以配一个**交互式提取工作区**（MinerU、图表数值化、跨文献候选定位），用来回答「原文有没有某个数据」这类临时查证。它不运行批次队列和闸门；批量交付仍走 `data_extraction_agent`。

## 交接与闸门

1. **状态真相只有一份**：`scripts/workflow_status.py`、SQLite/JSONL 队列、工件哈希与 receipt、人工验收记录。LangGraph checkpoint 和任何角色的口头汇报都不能覆盖它。
2. **阶段顺序**：检索 → 初筛 → 下载 → 解析 → 全文复筛 → 提取。上游闸门未通过，下游不得开工。
3. **异常先交 `recovery_agent`**；它不能自动修复时停止，交人工处理。
4. **候选不是结论**：交互式提取或 PaperQA/Luna 给出的数据都是候选；进入交付须经 `data_extraction_agent` 的合同与人工接受，或由人工回原页逐条核验。

## 归属规则

- **流水线代码和合同**放在本仓库；`runtime/`、`02_batches/` 等运行数据留在本地，不进 Git。
- **项目数据**与代码分开存放：同一套流水线可以服务多个项目，每个项目各存一份工作区数据，不互相引用路径。
- **下游使用方**（综述、论文写作、建模等）不属于本团队，只消费已验收的产物。综述证据卡由综述侧负责；本团队只产出全文、解析结果和候选证据。

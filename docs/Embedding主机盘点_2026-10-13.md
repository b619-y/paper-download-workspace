# Embedding 主机盘点（2026-10-13）

独立远程任务以只读方式检查了若干候选计算机，未安装软件、未启动服务、未停止进程。公共版本只保留选择依据，不披露 SSH 别名、硬件拓扑、磁盘使用量或账号权限细节。

| 结论 | 候选类型 | 实测状态 |
|---|---|---|
| 推荐 | GPU 计算节点 A | 显存、容器运行时和本地模型资产均满足 BGE-M3 部署；复用既有只读权重，不依赖公网下载。 |
| 有条件可用 | GPU 计算节点 B | 算力可用，但存储或容器权限不足；需先解决运维前提。 |
| 不建议 | GPU 计算节点 C | 可用显存、磁盘或运行时健康状态不足，不适合作为稳定服务端。 |

中文和长文优先 `BAAI/bge-m3`：多语言、长上下文并可同时提供 dense/sparse/multi-vector。只处理较短中文片段时可考虑 `bge-large-zh-v1.5`；E5-large-v2 官方定位偏英文，不作为中文首选。

用户随后授权在推荐节点部署。进一步核查发现该节点已有完整 BGE-M3 权重、FlagEmbedding 环境和可复用镜像，因此部署复用只读资产，不依赖公网下载。实际主机、设备和端口保留在不入库的部署配置中；公共运行接口见 `embedding_service/README.md`。
